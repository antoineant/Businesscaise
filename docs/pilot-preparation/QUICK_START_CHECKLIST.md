# Quick Start Checklist
## BusinessCaise Pilot Testing Guide

**Version:** 1.0
**Last Updated:** November 13, 2025
**Purpose:** Get your pilot simulation running in 60 minutes

---

## Pre-Pilot Checklist (1 Week Before)

### ☐ Platform Access
- [ ] Confirm you have GM Dashboard access
- [ ] Test login credentials
- [ ] Bookmark dashboard URL
- [ ] Verify you can create a test game

### ☐ Class Preparation
- [ ] Determine simulation dates (5 days recommended)
- [ ] Calculate number of teams (4 students per team ideal)
- [ ] Decide if you'll use pods (recommend for >12 teams)
- [ ] Choose company archetype and industry for your course

### ☐ Documentation Review
- [ ] Read GM User Guide (at least skim key sections)
- [ ] Print or share Team Player Guide with students
- [ ] Review sample scenarios for inspiration
- [ ] Prepare your scoring rubric

### ☐ Communication Plan
- [ ] Draft announcement email to students
- [ ] Prepare logistics (dates, times, expectations)
- [ ] Plan how students will form teams
- [ ] Schedule office hours for questions

## Day 1: Launch Day

### Morning Setup (30 minutes before start)

**☐ 15 Minutes Before:**
- [ ] Log into GM Dashboard
- [ ] Verify all teams have joined (check Teams tab)
- [ ] Review Session 1 settings one final time
- [ ] Have troubleshooting guide ready

**☐ At Start Time:**
- [ ] **UNLOCK SESSION 1**
- [ ] Send morning briefing narrative (if not already sent)
- [ ] Announce in class: "Session 1 is now live!"
- [ ] Monitor Teams tab for activity

**☐ First 15 Minutes:**
- [ ] Watch for team logins
- [ ] Respond to technical questions quickly
- [ ] Verify students can access narratives
- [ ] Check that Challenge tab is visible to teams

### Mid-Morning (30-60 minutes after start)

**☐ Monitor Progress:**
- [ ] Check submission count (Teams tab shows submission status)
- [ ] Send a mid-morning news narrative (optional)
- [ ] Respond to questions

**☐ As Submissions Arrive:**
- [ ] Review submission quality
- [ ] Start scoring when you have 3-4 to batch
- [ ] Provide constructive feedback

### Lunch Break

**☐ Scoring Session:**
- [ ] Score all Session 1 submissions
- [ ] Review feedback for consistency
- [ ] Check leaderboard - is it reasonable?
- [ ] Prepare Session 2 (afternoon)

### Afternoon Session

**☐ Unlock Session 2:**
- [ ] Edit Session 2 content if needed
- [ ] **UNLOCK SESSION 2**
- [ ] Send afternoon briefing/news
- [ ] Set deadline (typically 5:00 PM)

**☐ Repeat Process:**
- [ ] Monitor submissions
- [ ] Score as they come in
- [ ] Update leaderboard
- [ ] Note any issues for day 2 improvements

### End of Day 1

**☐ Evening Wrap-Up:**
- [ ] Finish all scoring for Day 1
- [ ] Review metrics distributions
- [ ] Prepare Day 2 narratives
- [ ] Send end-of-day recap (optional)

## Days 2-4: Ongoing Operation

### Daily Routine Template

**Each Morning (15 minutes):**
- [ ] Log in 15 min before session start
- [ ] Unlock morning session
- [ ] Send morning briefing narrative
- [ ] Create any additional narratives for context

**Mid-Morning (Variable):**
- [ ] Monitor submissions
- [ ] Score in batches (every 3-5 submissions)
- [ ] Use Reality Lens if creating new narratives
- [ ] Respond to questions

**Lunch (15-30 minutes):**
- [ ] Complete morning scoring
- [ ] Review leaderboard
- [ ] Prepare afternoon session
- [ ] Identify struggling teams for targeted support

**Afternoon (Variable):**
- [ ] Unlock afternoon session
- [ ] Send contextual narratives
- [ ] Continue scoring cycle
- [ ] Monitor pace

**End of Day (15 minutes):**
- [ ] Final scoring for the day
- [ ] Review overall progress
- [ ] Prepare next day's sessions
- [ ] Draft narratives for next morning

### Progressive Complexity

**Day 2:** Similar difficulty, establish rhythm
**Day 3:** Increase complexity slightly
**Day 4:** Introduce more ambiguous scenarios
**Day 5:** Culminating challenges, focus on integration

## Emergency Protocols

### If Platform Has Issues

**Immediate Actions:**
1. Notify students via email/class announcement
2. Extend affected deadline by issue duration
3. Document the issue with screenshots
4. Contact technical support
5. Have backup plan (extend deadline, skip session)

### If Students Can't Join

**Common Fixes:**
1. Verify they're using correct join link
2. Check for browser compatibility (try Chrome)
3. Clear browser cache/cookies
4. Try incognito mode
5. Verify game is not paused

### If Submissions Aren't Showing

**Troubleshooting:**
1. Check session is unlocked
2. Verify deadline hasn't passed
3. Have student try different browser
4. Check student is logged into correct team
5. Ask for screenshot of issue

### If Scoring Seems Wrong

**Resolution:**
1. Review scoring algorithm in GM Guide
2. Check if you accidentally scored twice
3. Use "Update Score" to correct
4. Metrics recalculate automatically
5. Explain correction to affected team if significant
